# Web Demo

Esta pasta será destinada à versão web experimental do projeto.

A demonstração web será utilizada principalmente para facilitar testes durante o desenvolvimento, permitindo:

- utilizar a câmera do navegador;
- enviar imagens para análise;
- visualizar a imagem original;
- visualizar o mapa de profundidade;
- destacar a região considerada como trajetória;
- visualizar a distância estimada;
- visualizar a classificação de risco.

Esta versão será utilizada como ambiente de testes antes da integração completa com o aplicativo Android.
