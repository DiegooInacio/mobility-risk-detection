# Android App

Esta pasta será destinada ao desenvolvimento do aplicativo Android do projeto.

O aplicativo será responsável por:

- capturar imagens da câmera do smartphone;
- executar ou consumir o modelo de estimativa de profundidade;
- analisar possíveis riscos na região frontal de deslocamento;
- gerar alertas por áudio e/ou vibração;
- oferecer uma interface acessível para pessoas com deficiência visual.

Inicialmente, a aplicação será desenvolvida utilizando Kotlin e CameraX. A estratégia de execução do modelo no dispositivo será definida durante os experimentos do projeto.
