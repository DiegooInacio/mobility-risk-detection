# Experiments

Esta pasta será utilizada para organizar os experimentos realizados durante o desenvolvimento e avaliação do projeto.

Os testes poderão incluir:

- avaliação da estimativa de profundidade;
- comparação entre distância real e estimada;
- detecção de riscos na trajetória;
- testes com imagens e vídeos;
- avaliação de falsos positivos e falsos negativos;
- testes de FPS e latência;
- desempenho do modelo em dispositivos móveis.

Os resultados obtidos poderão ser utilizados posteriormente na análise experimental do artigo científico.
